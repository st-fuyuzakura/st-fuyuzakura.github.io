# フォーム受付の設置手順

スタジオ用のGoogleアカウント（st.fuyuzakura@gmail.com）でログインした状態で進めてください。所要時間は10分ほどです。

## 1. スプレッドシートを作る
1. https://sheets.new を開く（新しいスプレッドシートができます）
2. 左上の「無題のスプレッドシート」を「Studio冬桜 依頼管理」に変える

## 2. コードを貼る
1. メニューの「拡張機能」→「Apps Script」を開く
2. 左上の「無題のプロジェクト」を「Studio冬桜 フォーム受付」に変える
3. 最初から入っている `function myFunction() { … }` をすべて消す
4. `gas/Code.gs` の中身をすべて貼り付けて、💾（保存）を押す
5. 左の ⚙️「プロジェクトの設定」→「タイムゾーン」を「(GMT+09:00) 東京」にする

## 3. 初回設定（setup）を実行する
1. 上のプルダウンで `setup` を選び、「▶ 実行」を押す
2. 「承認が必要です」→「権限を確認」→ スタジオ用アカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら、「詳細」→「Studio冬桜 フォーム受付（安全ではないページ）に移動」を押す
   （自分で作ったスクリプトなので問題ありません）
4. 「許可」を押す
5. スプレッドシートに「依頼」シートができていればOK

## 4. ウェブアプリとして公開する
1. 右上の「デプロイ」→「新しいデプロイ」
2. ⚙️ で種類を「ウェブアプリ」にする
3. 「次のユーザーとして実行」：**自分**
4. 「アクセスできるユーザー」：**全員**
5. 「デプロイ」を押し、表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をコピーしてClaudeに渡す

## 使い方（毎日の運用）
- 依頼が来ると「依頼」シートに1行増え、通知メールが届く
- 「見積もり」欄が「要・手動見積もり」のものは、見積もりメールを手で送り、ステータスを「見積もり済み」にする
- 入金を確認したら、ステータスを「入金済み」にする → 着手連絡が自動で送られる
- 「納品リンク」欄にURLを入れてから、ステータスを「納品」にする → 納品メールが自動で送られる
- 素材が後から届いたら、「素材リンク」欄に貼る（貼ればリマインドは送られない）
- 素材リンクが空のまま3日たつと、毎朝10時の確認でリマインドが1回だけ送られる

## コードを直したとき
「デプロイ」→「デプロイを管理」→ ✏️ →「バージョン」を「新バージョン」にして「デプロイ」。
こうするとURLは変わらない（「新しいデプロイ」にするとURLが変わってしまう）。
